# Deepstash

Website for **Deepstash** (深藏), an iPhone app for keeping track of the things at home: snap a photo and it's stored, with where it is, how many are left and when it expires. No account, no ads; data stays on the iPhone.

Served by GitHub Pages at https://sona-orbit.github.io/deepstash/

- Home, support and privacy pages in English, 繁體中文, 简体中文, 日本語, 한국어 and ไทย
- Static HTML and CSS, no JavaScript, no build step on this repository
- Contact: sona.orbit.hi@gmail.com
