# Deepstash

Website for **Deepstash** (深藏), an iPhone app for keeping track of the things at home: snap a photo and it's stored, with where it is, how many are left and when it expires. No account; data stays on the iPhone.

Served by GitHub Pages at https://sona-orbit.github.io/deepstash/

- Home, support and privacy pages in English, 繁體中文, 简体中文, 日本語, 한국어 and ไทย
- Static HTML and CSS; scripts are Google Analytics and a small inline video player. No build step on this repository
