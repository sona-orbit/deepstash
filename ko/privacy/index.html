개인정보 처리방침

최종 업데이트: 2026년 11월 11일

수집하는 정보

수집하는 정보는 없습니다. Deepstash에는 계정도 서버도 없습니다. 저장한 물건, 사진, 기억은 모두 사용자의 iPhone에만 있으며, 우리는 볼 수도 접근할 수도 없습니다.

바코드 조회

바코드를 스캔하면 앱이 상품 이름을 찾기 위해 바코드 번호를 Open Food Facts, Open Library 또는 Google Books로 보냅니다. 보내는 것은 번호뿐이며 사진이나 다른 정보는 보내지 않습니다.

AI

AI는 기본적으로 꺼져 있습니다. Apple 내장을 쓰면 네트워크 없이 iPhone에서 처리됩니다. 내 API 키를 쓰면 AI 버튼을 누를 때에 한해 해당 기능에 필요한 데이터가 선택한 서비스로 직접 전송되며, 그 서비스의 개인정보 처리방침에 따라 처리됩니다. API 키는 이 iPhone의 키체인에만 저장됩니다.

카메라, 사진, 알림

카메라는 물건을 찍고 바코드와 유통기한을 읽는 데, 사진 보관함은 사진을 고르는 데, 알림은 유통기한을 알리는 데 사용합니다. 모두 사용자가 사용하거나 켠 경우에만 쓰이며, 사진은 앱 안에만 보관됩니다.

광고와 추적

광고가 없으며, 분석 도구나 추적 도구도 사용하지 않습니다.

데이터 삭제

앱을 삭제하면 모든 데이터가 삭제됩니다. 앱에서 삭제한 물건은 30일 후 완전히 삭제됩니다.
