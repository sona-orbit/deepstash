최종 업데이트: 2026년 11월 11일

수집하는 정보 확인하기

당사는 직접 정보를 수집하지 않습니다. Deepstash에는 계정이나 서버가 없습니다. 저장한 물건, 사진, 추억은 iPhone에 남으며 당사는 이를 보거나 접근할 수 없습니다.

바코드 조회하기

바코드를 스캔하면 앱이 상품 이름을 조회하기 위해 바코드 번호를 Open Food Facts, Open Library 또는 Google Books로 보냅니다. 사진이나 다른 정보는 보내지 않습니다.

AI 사용하기

AI는 기본적으로 꺼져 있습니다. Apple 내장 기능을 선택하면 네트워크를 사용하지 않고 iPhone에서 처리합니다. 직접 준비한 API 키를 사용하는 경우에는 AI 버튼을 누를 때만 해당 기능에 필요한 데이터가 선택한 서비스로 직접 전송됩니다. 그 서비스는 자체 개인정보 처리방침에 따라 데이터를 처리합니다. API 키는 이 iPhone의 키체인에만 저장됩니다.

카메라·사진·알림 사용하기

카메라는 물건 촬영과 바코드·유통기한 읽기에, 사진 보관함은 사진 선택에, 알림은 유통기한 안내에 사용됩니다. 사용자가 기능을 사용하거나 켠 경우에만 접근하며 사진은 앱 안에 보관됩니다.

광고 확인하기

무료 버전은 홈, 장소, 검색 화면 아래에 Google AdMob 배너 광고를 표시합니다. 광고는 항상 개인 맞춤이 아니며 앱은 추적 권한을 요청하거나 물건, 사진, 추억을 광고주에게 제공하지 않습니다. 광고 게재와 성과 측정을 위해 Google은 기기 데이터와 대략적인 위치 정보를 받으며, Google의 개인정보 처리방침(policies.google.com/privacy)에 따라 처리합니다. 유럽 경제 지역, 영국, 스위스 사용자는 먼저 Google의 동의 양식을 보게 되며 설정의 광고 개인정보 보호 옵션에서 선택을 변경할 수 있습니다. Pro에서는 광고를 불러오지 않습니다.

결제 처리 확인하기

Pro 구매와 구독은 Apple이 처리합니다. 당사는 결제 정보를 받지 않습니다.

데이터 삭제하기

앱을 삭제하면 앱의 모든 데이터가 삭제됩니다. 앱 안에서 삭제한 물건은 30일 후 영구 삭제됩니다.
